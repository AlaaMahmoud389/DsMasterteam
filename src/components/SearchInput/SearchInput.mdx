      <li>Wire up <code>onClear</code> to reset your search results immediately</li>
      <li>Use <code>size="large"</code> for the primary search bar in a page header</li>
      <li>Provide a visible label or <code>aria-label</code> for accessibility</li>
    </ul>
  </div>

    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Don't use for password or email inputs — use TextInput with the appropriate type</li>
      <li>Don't hide the label in dense forms without providing an <code>aria-label</code></li>
      <li>Don't add an error state — SearchInput has no error variant; show result-count feedback instead</li>
      <li>Don't disable the mic button separately — it follows the field's disabled state</li>
    </ul>
  </div>
