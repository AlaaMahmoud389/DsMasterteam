<h2 id="usage" style={{ fontSize: 20, fontWeight: 700, color: '#000b36', marginBottom: 8 }}>Usage Guidelines</h2>

<div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: 20, marginBottom: 28 }}>
  <div style={{ border: '1.5px solid #d1fae5', borderRadius: 8, padding: '16px 18px', background: '#f0fdf4' }}>
    <div style={{ fontSize: 13, fontWeight: 700, color: '#065f46', marginBottom: 10 }}>Do</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Use <strong>Status Tags</strong> to communicate system or item lifecycle states (active, pending, error)</li>
      <li>Use <strong>Tags</strong> for taxonomy, categories, or metadata where icons add meaningful context</li>
      <li>Pick <code>inverted</code> type when a Status Tag must stand out strongly on a light background</li>
      <li>Use <code>ghost</code> type in dense layouts where the full background would create visual clutter</li>
      <li>Keep labels short — 1 to 3 words maximum for readability across all sizes</li>
      <li>Use semantic colour styles consistently — don't use <code>error</code> red for non-error states</li>
      <li>Ensure icon SVGs use <code>currentColor</code> so they adopt the correct colour token automatically</li>
    </ul>
  </div>
  <div style={{ border: '1.5px solid #fee2e2', borderRadius: 8, padding: '16px 18px', background: '#fff5f5' }}>
    <div style={{ fontSize: 13, fontWeight: 700, color: '#991b1b', marginBottom: 10 }}>Don't</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Don't mix Status Tags and Tags in the same group — they serve different purposes</li>
      <li>Don't use more than two or three tags in a row — group into a chip list if you need more</li>
      <li>Don't use <code>xsmall</code> size for long labels — text becomes illegible at 10 px</li>
      <li>Don't hardcode icon colour via the SVG's fill/stroke — always use <code>currentColor</code></li>
      <li>Don't use <code>iconOnly</code> without a tooltip — the icon alone carries no accessible label</li>
      <li>Don't combine <code>leadIcon</code> and <code>iconOnly</code> with a <code>trailIcon</code> and expect the trail to show — leadIcon takes priority in icon-only mode</li>
    </ul>
  </div>
</div>
