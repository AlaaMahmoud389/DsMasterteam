## Step Progression

The arc fills clockwise from 12 o'clock. Progress = `currentStep ÷ totalSteps`.

<div style={{ display: 'flex', flexDirection: 'column', gap: 20, marginBottom: 16 }}>
  {['primary','neutral'].map(v => (
    <div key={v} style={{ background: '#fff', border: '1px solid #e5e7eb', borderRadius: 10, padding: '20px 24px' }}>
      <div style={{ fontSize: 11, fontWeight: 700, textTransform: 'uppercase', letterSpacing: '.08em', color: '#6b7280', marginBottom: 16 }}>{v}</div>
      <div style={{ display: 'flex', gap: 20, alignItems: 'center', flexWrap: 'wrap' }}>
        {[1,2,3,4].map(step => (
          <div key={step} style={{ display: 'flex', flexDirection: 'column', alignItems: 'center', gap: 8 }}>
            <CircularStepper size="xl" currentStep={step} totalSteps={4} variant={v} />
            <span style={{ fontSize: 11, color: '#6b7280' }}>{Math.round(step/4*100)}%</span>
          </div>
        ))}
      </div>
    </div>
  ))}
</div>

| Step | Progress | Arc fill |
|---|---|---|
| 1 of 4 | 25% | ¼ clockwise |
| 2 of 4 | 50% | ½ clockwise |
| 3 of 4 | 75% | ¾ clockwise |
| 4 of 4 | 100% | Full circle |

## Code Examples

```jsx
import { CircularStepper } from '@/components/CircularStepper';

// Indicator only — default size + primary variant
<CircularStepper currentStep={2} totalSteps={4} />

// Neutral variant
<CircularStepper currentStep={3} totalSteps={5} variant="neutral" />

// Large size
<CircularStepper currentStep={1} totalSteps={4} size="xl" variant="primary" />

// Full variant — with label, description, navigation
<CircularStepper
  currentStep={2}
  totalSteps={4}
  size="xl"
  variant="primary"
  label="Step Two"
  description="Fill in your contact information to continue."
  onBack={() => setStep(s => s - 1)}
  onNext={() => setStep(s => s + 1)}
/>

// Dark theme
<CircularStepper
  currentStep={1}
  totalSteps={4}
  size="lg"
  variant="primary"
  theme="dark"
  label="Step One"
  description="This is step description"
  onNext={() => {}}
/>

// RTL Arabic
<CircularStepper
  currentStep={1}
  totalSteps={4}
  size="xl"
  variant="primary"
  dir="rtl"
  label="الخطوة الأولى"
  description="يكتب المحتوى الإضافي هنا في حال ان عنوان الاختيار يحتاج إلى شرح."
  onNext={() => {}}
/>

// Controlled interactive stepper
const [step, setStep] = useState(1);
const TOTAL = 4;

<CircularStepper
  currentStep={step}
  totalSteps={TOTAL}
  size="xl"
  variant="primary"
  label={`Step ${step} of ${TOTAL}`}
  onBack={step > 1     ? () => setStep(s => s - 1) : undefined}
  onNext={step < TOTAL ? () => setStep(s => s + 1) : undefined}
/>
```
