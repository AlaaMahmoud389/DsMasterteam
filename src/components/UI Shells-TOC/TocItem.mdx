## RTL Support

TocItem uses **physical CSS mirroring** — no `dir="rtl"` on the container. This ensures `align-items: flex-start/end` resolves to physical left/right, not logical start/end, matching the Figma layout exactly.

</div>

```jsx
<TocItem rtl={false} textEn="Page Section" textAr="قسم صفحة" level="Level 2 (H3)" selected />

{/* RTL — Arabic */}
<TocItem rtl={true} textEn="Page Section" textAr="قسم صفحة" level="Level 2 (H3)" selected />
```
