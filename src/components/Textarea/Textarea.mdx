<h2 id="usage" style={{ fontSize: 20, fontWeight: 700, color: '#000b36', marginBottom: 8 }}>Usage Guidelines</h2>

<div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: 20, marginBottom: 28 }}>
  <div style={{ border: '1.5px solid #d1fae5', borderRadius: 8, padding: '16px 18px', background: '#f0fdf4' }}>
    <div style={{ fontSize: 13, fontWeight: 700, color: '#065f46', marginBottom: 10 }}>Do</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Use Textarea for multi-line free-form input (messages, descriptions, comments)</li>
      <li>Use a helper text to indicate character limits or formatting requirements</li>
      <li>Match the <code>variant</code> to the surrounding form fields (all default or all filled)</li>
      <li>Use the controlled pattern with <code>value</code> + <code>onChange</code> to drive live character counts</li>
      <li>Keep the default 96 px height — resize is available for users who need more space</li>
    </ul>
  </div>
  <div style={{ border: '1.5px solid #fee2e2', borderRadius: 8, padding: '16px 18px', background: '#fff5f5' }}>
    <div style={{ fontSize: 13, fontWeight: 700, color: '#991b1b', marginBottom: 10 }}>Don't</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Don't use Textarea for single-line input — use TextInput instead</li>
      <li>Don't set a very small height that hides content — 96 px is the enforced minimum</li>
      <li>Don't use prefix/suffix affixes — they are not available on Textarea</li>
      <li>Don't use <code>autoPlay</code> or other single-line-only attributes</li>
      <li>Don't forget to pair a visible label or <code>aria-label</code> — placeholder text alone is not accessible</li>
    </ul>
  </div>
</div>
