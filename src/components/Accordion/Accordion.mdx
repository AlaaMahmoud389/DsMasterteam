## State Table

**Focus ring** — implemented as double `box-shadow` (2px `#1849a9` + 5px `#ffffff`), matching the project's Button focus pattern. Figma specifies a 1px `accordion/border/default` border which does not meet WCAG 2.2 Focus Appearance contrast requirements — see Mismatch Report.

**Disabled** — text changes to `accordion/header-text/secondary = #3c5073`. The accordion uses its own disabled token, not the shared `--color-disabled-text: #6c7c96` used by Button.

import { Accordion } from '@/components/Accordion';

// Basic single-open accordion
<Accordion
  type="single"
  size="lg"
  items={[
    { title: 'What is an accordion?', content: 'Progressive disclosure component.' },
    { title: 'When to use it?', content: 'When content is optional and space is limited.' },
  ]}
/>

// Multiple open with a default open item
<Accordion
  type="multiple"
  size="md"
  items={[
    { title: 'Section A', content: 'Content A', defaultOpen: true },
    { title: 'Section B', content: 'Content B' },
  ]}
/>

// With leading icon
<Accordion
  iconAlignment="leading"
  items={[{ title: 'Leading chevron', content: 'Chevron appears before the title.' }]}
/>

// RTL Arabic
<Accordion
  dir="rtl"
  type="single"
  items={[
    { title: 'ما هو الأكورديون؟', content: 'المحتوى هنا...' },
    { title: 'متى تستخدمه؟', content: 'المحتوى هنا...', defaultOpen: true },
  ]}
/>

// Disabled item
<Accordion
  items={[
    { title: 'Available', content: 'Clickable.' },
    { title: 'Unavailable', content: 'Cannot expand.', disabled: true },
  ]}
/>

<div style={{ border: '1px solid #e5e7eb', borderRadius: 8 }}>
  <Accordion
    flush={true}
    items={[{ title: 'Flush item', content: 'No item borders.' }]}
  />
</div>
