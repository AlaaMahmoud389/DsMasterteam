## State Table

| State | Trigger | Primary bg | Neutral bg | Icon |
|---|---|---|---|---|
| Default (unchecked) | Resting | `#ffffff` + gray border | `#ffffff` + gray border | — |
| Hover (unchecked) | `:hover` | `#f3f4f6` ripple | `#f3f4f6` ripple | — |
| Pressed (unchecked) | `:active` | `#e5e7eb` | `#e5e7eb` | — |
| Default (checked) | `checked=true` | `#1849a9` | `#1f2a37` | white `#f9fafb` |
| Hover (checked) | `:hover` | `#194185` | `#0d121c` | white |
| Pressed (checked) | `:active` | `#102a56` | `#4d5761` | white |
| Focused | `:focus-visible` | unchanged + ring | unchanged + ring | unchanged |
| Read-only (checked) | `readOnly=true` | white + blue border | white + gray border | blue / dark |
| Disabled | `disabled=true` | `#d2d6db` | `#d2d6db` | `#6c7c96` |

**Focus ring:** `box-shadow: 0 0 0 2px #ffffff, 0 0 0 4px #00001c` (white inner gap + dark navy outer ring).

**Disabled** uses dedicated tokens (`--checkbox-disabled-bg: #d2d6db` / `--checkbox-disabled-icon: #6c7c96`), never opacity.

## Code Examples

```jsx
import { Checkbox, CheckboxGroup } from '@/components/Checkbox';

// Basic unchecked
<Checkbox label="Accept terms" />

// Controlled checked — primary
<Checkbox
  checked={isChecked}
  onChange={(e) => setIsChecked(e.target.checked)}
  label="Email notifications"
  variant="primary"
  size="md"
/>

// Neutral variant
<Checkbox checked={true} variant="neutral" label="Neutral option" />

// With description and error
<Checkbox
  checked={false}
  label="I agree to the privacy policy"
  description="Your data is protected under our privacy agreement."
  error="You must accept the privacy policy to continue."
  onChange={handleChange}
/>

// Indeterminate (parent of partial selection)
<Checkbox
  checked={allSelected}
  indeterminate={someSelected && !allSelected}
  label="Select all"
  onChange={handleSelectAll}
/>

// Read-only
<Checkbox readOnly checked={true} label="Confirmed preference" />

// Disabled
<Checkbox disabled checked={false} label="Unavailable option" />

// RTL Arabic
<Checkbox
  dir="rtl"
  checked={false}
  label="عنوان اختيار متعدد"
  description="يكتب المحتوى الإضافي هنا في حال ان عنوان الاختيار يحتاج إلى شرح."
  onChange={handleChange}
/>

// Group with legend
<CheckboxGroup legend="Notification preferences">
  <Checkbox checked={emailOn} label="Email" onChange={toggleEmail} />
  <Checkbox checked={smsOn}   label="SMS"   onChange={toggleSms}   />
  <Checkbox checked={pushOn}  label="Push"  onChange={togglePush}  />
</CheckboxGroup>
```
