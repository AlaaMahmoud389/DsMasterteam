{/* ── Usage Guidelines ── */}
<h2 id="usage" style={{ fontSize: 20, fontWeight: 700, color: '#000b36', marginBottom: 8 }}>Usage Guidelines</h2>

<div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: 20, marginBottom: 28 }}>
  <div style={{ border: '1.5px solid #d1fae5', borderRadius: 8, padding: '16px 18px', background: '#f0fdf4' }}>
    <div style={{ fontSize: 13, fontWeight: 700, color: '#065f46', marginBottom: 10 }}>Do</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Use for multiple independent options that can be selected simultaneously</li>
      <li>Group related checkboxes in a <code>CheckboxGroup</code> with a descriptive legend</li>
      <li>Use <code>indeterminate</code> on a parent checkbox when only some children are selected</li>
      <li>Add <code>description</code> text when the label alone is insufficient</li>
      <li>Use <code>primary</code> variant for most forms; <code>neutral</code> for dark-themed contexts</li>
      <li>Use <code>size="md"</code> as the default; only downsize when space is constrained</li>
      <li>Test with keyboard — all checkboxes must be Tab-reachable and Space-toggleable</li>
    </ul>
  </div>
  <div style={{ border: '1.5px solid #fee2e2', borderRadius: 8, padding: '16px 18px', background: '#fff5f5' }}>
    <div style={{ fontSize: 13, fontWeight: 700, color: '#991b1b', marginBottom: 10 }}>Don't</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Don't use for mutually exclusive options — use Radio instead</li>
      <li>Don't use for a single on/off toggle — use a Switch component</li>
      <li>Don't mix sizes within the same group</li>
      <li>Don't disable all items — always leave at least one interactive</li>
      <li>Don't mix <code>primary</code> and <code>neutral</code> variants within the same group</li>
      <li>Don't rely on color alone to communicate error — always use the <code>error</code> prop</li>
      <li>Don't use <code>indeterminate</code> as a permanent state — it should reflect partial child selection</li>
    </ul>
  </div>
</div>
