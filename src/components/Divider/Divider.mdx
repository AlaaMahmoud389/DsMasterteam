{/* ── Usage Guidelines ── */}
<h2 id="usage" style={{ fontSize: 20, fontWeight: 700, color: '#000b36', marginBottom: 8 }}>Usage Guidelines</h2>

<div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: 20, marginBottom: 28 }}>
  <div style={{ border: '1.5px solid #d1fae5', borderRadius: 8, padding: '16px 18px', background: '#f0fdf4' }}>
    <div style={{ fontSize: 13, fontWeight: 700, color: '#065f46', marginBottom: 10 }}>Do</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Use to separate logically distinct content sections or columns</li>
      <li>Make the parent a flex container with a defined height when using a vertical divider — <code>height: 100%</code> requires a sized ancestor</li>
      <li>Use <code>solidWhite</code> only on the dark <code>#000B36</code> on-color background</li>
      <li>Use <code>primary</code> on light or white backgrounds for a prominent visual break</li>
      <li>Use <code>neutral</code> for subtle, decorative separation in both default and on-color contexts</li>
    </ul>
  </div>
  <div style={{ border: '1.5px solid #fee2e2', borderRadius: 8, padding: '16px 18px', background: '#fff5f5' }}>
    <div style={{ fontSize: 13, fontWeight: 700, color: '#991b1b', marginBottom: 10 }}>Don't</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Don't use <code>solidWhite</code> on light backgrounds — it will be invisible or jarring</li>
      <li>Don't set a fixed width or height on the divider element — let the parent control dimensions</li>
      <li>Don't use a divider to add spacing — use padding or gap instead; dividers are semantic separators, not spacers</li>
      <li>Don't stack multiple dividers back-to-back without meaningful content between them</li>
    </ul>
  </div>
</div>
