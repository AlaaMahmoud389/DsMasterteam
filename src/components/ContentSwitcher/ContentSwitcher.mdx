{/* ── Usage Guidelines ── */}
<h2 id="usage" style={{ fontSize: 20, fontWeight: 700, color: '#000b36', marginBottom: 8 }}>Usage Guidelines</h2>

<div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: 20, marginBottom: 28 }}>
  <div style={{ border: '1.5px solid #d1fae5', borderRadius: 8, padding: '16px 18px', background: '#f0fdf4' }}>
    <div style={{ fontSize: 13, fontWeight: 700, color: '#065f46', marginBottom: 10 }}>Do</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Use for mutually exclusive options only — exactly one item must be active at a time.</li>
      <li>Keep labels short (1–2 words). Long labels break the compact visual rhythm.</li>
      <li>Use 2–4 items. More than 4 should be a dropdown or tabs instead.</li>
      <li>Use <code style={{ fontSize: 12 }}>onColor</code> on dark/coloured backgrounds for sufficient contrast.</li>
      <li>Provide a meaningful <code style={{ fontSize: 12 }}>ariaLabel</code> for screen reader context.</li>
      <li>Provide <code style={{ fontSize: 12 }}>labelAr</code> when using <code style={{ fontSize: 12 }}>dir="rtl"</code> so Arabic text is displayed.</li>
    </ul>
  </div>
  <div style={{ border: '1.5px solid #fee2e2', borderRadius: 8, padding: '16px 18px', background: '#fff5f5' }}>
    <div style={{ fontSize: 13, fontWeight: 700, color: '#991b1b', marginBottom: 10 }}>Don't</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Don't use for multi-select — that's a Chip group or a set of checkboxes.</li>
      <li>Don't use more than 4 items — legibility and touch target size degrade.</li>
      <li>Don't use on a white/light background with <code style={{ fontSize: 12 }}>onColor=true</code> — the dark fills will look out of place.</li>
      <li>Don't mix different sizes in the same switcher.</li>
      <li>Don't use as navigation between separate pages — use Tabs or a nav pattern instead.</li>
      <li>Don't disable all items — at least one should remain selectable at all times.</li>
    </ul>
  </div>
</div>
