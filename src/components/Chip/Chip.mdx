  <div style={{ border: '1.5px solid #d1fae5', borderRadius: 8, padding: '16px 18px', background: '#f0fdf4' }}>
    <div style={{ fontSize: 13, fontWeight: 700, color: '#065f46', marginBottom: 10 }}>Do</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Use chips for filtering, tagging, or multi-select inputs</li>
      <li>Use Primary for brand-coloured interactive selection chips</li>
      <li>Use Neutral for secondary, system-generated, or content tags</li>
      <li>Use <code>onColor</code> when chips sit on a coloured hero area or card header</li>
      <li>Use <code>showCloseButton</code> for dismissible filter chips</li>
      <li>Supply <code>labelAr</code> whenever <code>dir="rtl"</code> so Arabic users see the correct text</li>
    </ul>
  </div>
  <div style={{ border: '1.5px solid #fee2e2', borderRadius: 8, padding: '16px 18px', background: '#fff5f5' }}>
    <div style={{ fontSize: 13, fontWeight: 700, color: '#991b1b', marginBottom: 10 }}>Don't</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Don't use chips as primary navigation — use buttons or tabs instead</li>
      <li>Don't mix <code>onColor</code> chips with regular chips in the same group</li>
      <li>Don't omit <code>onClose</code> when <code>showCloseButton=true</code></li>
      <li>Don't use chips for actions that load a new page — use links or buttons</li>
      <li>Don't show more than one close button per chip</li>
      <li>Don't use Disabled chips without communicating why the action is unavailable</li>
    </ul>
  </div>
