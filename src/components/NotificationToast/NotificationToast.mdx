## Dismiss Animation

Both the **Notification banner** and **Notification Toast** include built-in dismiss animations triggered when the close button is clicked.

```jsx
// Animation is fully internal — just wire onDismiss to remove from state
const [toasts, setToasts] = useState([{ id: 1, variant: 'Info' }]);

<NotificationToast
  variant="Info"
  onDismiss={() => setToasts(prev => prev.filter(t => t.id !== 1))}
/>
// The component plays the exit animation, then calls onDismiss when it completes.
// Remove the item from state inside onDismiss — not before.
```

  <strong>Important:</strong> Remove the toast from state <strong>inside</strong> <code>onDismiss</code> (called <em>after</em> the animation ends), not when the button is clicked. Removing it immediately will cut the animation short.

## Implementation Examples

```jsx
import { NotificationToast } from '@/components/NotificationToast';

// Basic usage
<NotificationToast
  variant="Success"
  title="Profile saved"
  description="Your changes have been saved successfully."
  onDismiss={() => setVisible(false)}
/>

// With action buttons
<NotificationToast
  variant="Info"
  title="New update available"
  description="Version 2.4.0 includes performance improvements."
  actions={true}
  action1Label="Update now"
  action2Label="Later"
  onAction1={handleUpdate}
  onAction2={handleDismiss}
  onDismiss={() => setVisible(false)}
/>

// Mobile size
<NotificationToast
  variant="Warning"
  mobile={true}
  title="Low storage"
  description="You have less than 500MB remaining."
  onDismiss={() => setVisible(false)}
/>

// RTL Arabic
<NotificationToast
  variant="Success"
  rtl={true}
  title="تم الحفظ بنجاح"
  description="تم حفظ جميع التغييرات بنجاح."
  onDismiss={() => setVisible(false)}
/>

// Persistent (no auto-dismiss, no close button)
<NotificationToast
  variant="Critical/Error"
  closeButton={false}
  title="Connection lost"
  description="Attempting to reconnect..."
/>

// Controlled toast stack — animate then remove from state
const [toasts, setToasts] = useState([]);

const addToast = (variant, title) =>
  setToasts(prev => [...prev, { id: Date.now(), variant, title }]);

const removeToast = (id) =>
  setToasts(prev => prev.filter(t => t.id !== id));

// Auto-dismiss after 5s for non-critical
useEffect(() => {
  const id = setTimeout(() => onDismiss?.(), 5000);
  return () => clearTimeout(id);
}, []);

{toasts.map(toast => (
  <NotificationToast
    key={toast.id}
    variant={toast.variant}
    title={toast.title}
    onDismiss={() => removeToast(toast.id)}
  />
))}
```
