## RTL Support

<div style={{ display: 'flex', flexWrap: 'wrap', gap: 24, alignItems: 'flex-start', marginBottom: 16 }}>
  <Modal rtl={true} title="عنوان الرسالة يُكتب هنا" description="يُكتب المحتوى الاضافي هنا في حال أن رسالة الاشعار أو التنبيه تحتاج الى شرح أو تفصيل." primaryActionLabel="إجراء" secondaryActionLabel="إجراء" tertiaryActionLabel="إجراء" />
  <Modal rtl={true} mobile={true} title="عنوان الرسالة يُكتب هنا" description="يُكتب المحتوى الاضافي هنا في حال أن رسالة الاشعار أو التنبيه تحتاج الى شرح أو تفصيل." primaryActionLabel="إجراء" secondaryActionLabel="إجراء" tertiaryActionLabel="إجراء" />
</div>

Setting `rtl={true}` adds `dir="rtl"` to the root element. The browser automatically mirrors all flex directions. Key RTL behaviors:

- **Close button** — moves to top-left via `inset-inline-end` (CSS logical property)
- **Title and description** — right-aligned (`text-align: right`)
- **Arrow icons** — flipped horizontally with `transform: scaleX(-1)` so arrows point in the semantically correct direction
- **Desktop actions** — Tertiary moves to the right, Primary+Secondary to the left

## Usage Guidelines

<div style={{ display: 'flex', flexWrap: 'wrap', gap: 16, marginBottom: 16 }}>
<div style={{ flex: '1 1 280px', background: '#f0fdf4', border: '1px solid #bbf7d0', borderRadius: 10, padding: '16px 20px' }}>
  <div style={{ fontWeight: 700, color: '#15803d', marginBottom: 8, fontSize: 13 }}>✓ Do</div>
  <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#166534', lineHeight: 1.8 }}>
    <li>Use for actions requiring explicit user confirmation</li>
    <li>Keep title concise — one clear sentence</li>
    <li>Use description only when additional context genuinely helps</li>
    <li>Trap keyboard focus inside the modal while open</li>
    <li>Move focus back to the trigger element when the modal closes</li>
    <li>Support Escape key to close</li>
    <li>Use mobile layout on small viewports</li>
  </ul>
</div>
<div style={{ flex: '1 1 280px', background: '#fff1f2', border: '1px solid #fecdd3', borderRadius: 10, padding: '16px 20px' }}>
  <div style={{ fontWeight: 700, color: '#be123c', marginBottom: 8, fontSize: 13 }}>✗ Don't</div>
  <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#9f1239', lineHeight: 1.8 }}>
    <li>Don't use modals for non-blocking notifications — use Inline Alert or Toast</li>
    <li>Don't stack multiple modals</li>
    <li>Don't put excessive content or forms inside the modal card</li>
    <li>Don't leave background content interactive while modal is open</li>
    <li>Don't omit a way to dismiss (at minimum, provide a close button)</li>
    <li>Don't auto-close without user action on confirmation modals</li>
  </ul>
</div>
</div>

## Implementation Examples

```jsx
import { Modal } from '@/components/Modal';

// Basic usage
<Modal
  title="Confirm Action"
  description="This will permanently delete the record. Are you sure?"
  primaryActionLabel="Delete"
  secondaryActionLabel="Cancel"
  tertiaryActionLabel="Learn more"
  onClose={() => setOpen(false)}
  onPrimaryAction={handleDelete}
  onSecondaryAction={() => setOpen(false)}
  onTertiaryAction={openHelpCenter}
/>

// Mobile layout
<Modal mobile title="Confirm" onClose={close} />

// RTL / Arabic
<Modal
  rtl
  title="عنوان الرسالة يُكتب هنا"
  description="يُكتب المحتوى الاضافي هنا في حال أن رسالة الاشعار أو التنبيه تحتاج الى شرح أو تفصيل."
  primaryActionLabel="إجراء"
  secondaryActionLabel="إجراء"
  tertiaryActionLabel="إجراء"
  onClose={close}
/>

// Non-dismissible, no actions (info-only)
<Modal
  dismissible={false}
  showActions={false}
  title="Processing…"
  description="Please wait while we process your request."
/>
```

**Page-level wiring pattern:**

```jsx
const [modalOpen, setModalOpen] = useState(false);

// Render backdrop + modal card
{modalOpen && (
  <div
    style={{
      position: 'fixed', inset: 0,
      background: 'rgba(0,0,0,0.45)',
      display: 'flex', alignItems: 'center', justifyContent: 'center',
      zIndex: 1000,
    }}
    onClick={() => setModalOpen(false)}
  >
    <div onClick={(e) => e.stopPropagation()}>
      <Modal
        onClose={() => setModalOpen(false)}
        onPrimaryAction={handleConfirm}
        onSecondaryAction={() => setModalOpen(false)}
        onTertiaryAction={handleTertiary}
      />
    </div>
  </div>
)}
```
