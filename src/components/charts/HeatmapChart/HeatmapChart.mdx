## Color Bands

The heatmap maps each cell value to one of 7 discrete color bands sourced from Figma series tokens. Band 0 (null/grey) represents zero or missing data.

<div style={{ border: '1px solid #e5e7eb', borderRadius: 10, overflow: 'hidden', marginBottom: 16 }}>
<div style={{ background: '#f9fafb', padding: '8px 16px', borderBottom: '1px solid #e5e7eb', fontSize: 11, fontWeight: 700, textTransform: 'uppercase', letterSpacing: '.08em', color: '#6b7280' }}>7-band color scale (scaleMax = 40)</div>
{[
['0', 'Null / Zero', '#d2d6db', 'var(--chart-null, #d2d6db)', 'value = null or 0'],
['1', 'Lightest', '#d1e9ff', 'var(--chart-series-6, #d1e9ff)', '1 – 6.66'],
['2', 'Light', '#b2ddff', 'var(--chart-series-5, #b2ddff)', '6.67 – 13.33'],
['3', 'Mid-light', '#53b1fd', 'var(--chart-series-4, #53b1fd)', '13.34 – 20'],
['4', 'Mid', '#2e90fa', 'var(--chart-series-3, #2e90fa)', '20.01 – 26.66'],

['6', 'Darkest', '#1849a9', 'var(--chart-series-1, #1849a9)', '33.34 – 40'],
].map(([idx, name, hex, token, range]) => (
  <div key={idx} style={{ display: 'grid', gridTemplateColumns: '32px 100px 40px 260px 1fr', alignItems: 'center', gap: 0, borderBottom: '1px solid #f3f4f6', fontSize: 13 }}>

      <div style={{ width: 24, height: 24, borderRadius: 4, background: hex, border: '1px solid #e5e7eb' }} />
    </div>

    <div style={{ padding: '8px 10px', color: '#374151' }}>{range}</div>
  </div>
))}

The `getBand(value, scaleMax)` function linearly maps `value / scaleMax` to bands 1–6. Values of `null` or `0` always resolve to band 0 (grey).

Cells with a value of `0` or `null` render in the grey null band (`--chart-null, #d2d6db`), making gaps in the data immediately visible.

## Do / Don't

<div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: 24, marginBottom: 24 }}>

<div style={{ border: '1px solid #bbf7d0', borderRadius: 10, overflow: 'hidden' }}>
  <div style={{ background: '#f0fdf4', padding: '8px 16px', borderBottom: '1px solid #bbf7d0', display: 'flex', alignItems: 'center', gap: 8 }}>
    <span style={{ color: '#16a34a', fontSize: 16, fontWeight: 700 }}>✓</span>
    <span style={{ fontSize: 13, fontWeight: 700, color: '#166534' }}>Do</span>
  </div>
  <div style={{ padding: 16, fontSize: 13, color: '#374151', lineHeight: 1.7 }}>
    <ul style={{ margin: 0, paddingLeft: 18 }}>
      <li>Provide consistent `data` dimensions matching `rowLabels` and `colLabels` lengths.</li>
      <li>Use `scaleMax` set to the actual maximum value in your data for meaningful color distribution.</li>
      <li>Show the color scale bar (`showColorScale=true`) whenever the context is unfamiliar to the reader.</li>
      <li>Include both `yAxisTitle` and `xAxisTitle` to clarify what the axes represent.</li>
      <li>Use `null` for missing data rather than `0` when the distinction matters semantically.</li>
    </ul>
  </div>
</div>

<div style={{ border: '1px solid #fecaca', borderRadius: 10, overflow: 'hidden' }}>
  <div style={{ background: '#fef2f2', padding: '8px 16px', borderBottom: '1px solid #fecaca', display: 'flex', alignItems: 'center', gap: 8 }}>
    <span style={{ color: '#dc2626', fontSize: 16, fontWeight: 700 }}>✗</span>
    <span style={{ fontSize: 13, fontWeight: 700, color: '#991b1b' }}>Don't</span>
  </div>
  <div style={{ padding: 16, fontSize: 13, color: '#374151', lineHeight: 1.7 }}>
    <ul style={{ margin: 0, paddingLeft: 18 }}>
      <li>Don't set `scaleMax` much higher than the data maximum — this compresses all cells into the light end of the scale.</li>
      <li>Don't use more than ~24 columns — very narrow cells become unreadable and hard to click.</li>
      <li>Don't omit `rowLabels` and `colLabels` — tooltips will fall back to generic "Row N / Col N" identifiers.</li>
      <li>Don't rely solely on color to convey meaning — always provide the tooltip for accessible value disclosure.</li>
      <li>Don't use the heatmap for continuous trends — use a line or area chart instead.</li>
    </ul>
  </div>
