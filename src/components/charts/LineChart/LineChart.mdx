  <div style={{ padding: 16, fontSize: 13, color: '#374151', lineHeight: 1.7 }}>
    <ul style={{ margin: 0, paddingLeft: 18 }}>
      <li>Provide the same number of data points in every series as entries in `categories`.</li>
      <li>Use `showYAxisLabel` / `showXAxisLabel` / `showContent` to match the specific Figma variant needed in your layout.</li>
      <li>Set `maxValue` explicitly when you need the Y-axis scale to stay consistent across multiple charts.</li>
      <li>Use `lineType="smooth"` for gradual data trends; `"step"` for discrete state changes.</li>
      <li>Enable `showLegend={true}` whenever there are 2+ series to help users distinguish them.</li>
    </ul>
  </div>
</div>

<div style={{ border: '1px solid #fecaca', borderRadius: 10, overflow: 'hidden' }}>

    <span style={{ color: '#dc2626', fontSize: 16, fontWeight: 700 }}>✗</span>
    <span style={{ fontSize: 13, fontWeight: 700, color: '#991b1b' }}>Don't</span>
  </div>
  <div style={{ padding: 16, fontSize: 13, color: '#374151', lineHeight: 1.7 }}>
    <ul style={{ margin: 0, paddingLeft: 18 }}>
      <li>Don't pass more than 6 series — the color palette only covers 6 tokens and additional series will cycle colors.</li>
      <li>Don't omit `categories` — it is required; passing an empty array renders the empty state.</li>
