## KPI Block

The KPI block (`showKpi={true}`) renders a large metric value, a trend icon, a percentage badge, and a context label below the chart title. Sourced from Figma node 4560:4600.

**KPI prop shape:**
```js
kpi: {
  value: '78,909.72',           // display string — pre-formatted
  badge: {
    icon:  '↑',                 // '↑' | '↓' | '' — trend direction
    text:  '4.5%',              // percentage or delta
    label: 'from last week',    // context label
  },
}
```
