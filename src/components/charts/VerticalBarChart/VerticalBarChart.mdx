| State | Data condition | Visual behavior |
|---|---|---|
| Loading | Awaiting API response | Static skeleton using styled divs with `--chart-skeleton` (#e7e9ed) fill |
| Empty | `series={[]}` or `categories={[]}` | Chart title visible; SVG renders empty plot area with auto-generated ticks |
| Partial data | Some data points are `0` | Zero bars invisible; axis scale set by max non-zero value |
| Long labels | Category name > 6 chars | SVG clips label text at column width — switch to Horizontal Bar Chart |
| High values | Numbers > 100,000 | Axis ticks auto-step; pre-format `kpi.value` for locale display |
| Zero values | One or more values = 0 | Zero bars invisible; tooltip still shows "0" on hover |

## Data Format

```js
// Single series
const series = [
  { id: 1, label: 'Active Users', data: [500, 240, 270, 180, 430, 200, 130] }
];
const categories = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul'];

// Multi-series (group or stacked)
const groupSeries = [
  { id: 1, label: 'Series 1', data: [300, 280, 300, 290] },
  { id: 2, label: 'Series 2', data: [200, 185, 220, 170] },
  { id: 3, label: 'Series 3', data: [100, 110, 130, 90] },
];
// categories.length must equal series[n].data.length

// KPI block
const kpi = {
  value: '78,909.72',
  badge: { icon: '↑', text: '4.5%', label: 'from last week' }
};
```

| Field | Type | Required | Notes |
|---|---|---|---|
| `series[].label` | `string` | Yes | Legend text + accessible name |
| `series[].data` | `number[]` | Yes | One value per category |
| `series[].color` | `string` | No | Override series color (CSS value) |
| `categories` | `string[]` | Yes | X-axis labels; length = data length |
| `kpi.value` | `string` | No | Formatted number string |
| `kpi.badge.text` | `string` | No | e.g. `"4.5%"` |
| `kpi.badge.label` | `string` | No | e.g. `"from last week"` |

| Rule | Do | Don't | Reason |
|---|---|---|---|
| Use vertical bars for short labels | Use Jan, Feb, Mar | Use "Engineering Department" | Long labels crowd the X-axis |
| Start axis at zero | Y-axis starts at 0 | Truncated Y-axis at non-zero | Exaggerates differences |
| Keep grouped bars limited | 2–3 series | 5+ series | Too many bars reduce readability |
| Long labels → Horizontal chart | Switch to Horizontal Bar Chart | Rotate many long labels | Improves readability significantly |
| Part-to-whole | Stacked with 3–4 segments | Stacked with 6+ segments | Too many segments to compare |
| Legend | Always show for multi-series | Hide for multi-series | Color independence required |
