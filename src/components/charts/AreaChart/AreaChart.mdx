## KPI Block

The KPI block (`showKpi` + `kpi` prop) displays a large metric value above the chart with an optional trend badge.

```jsx
<AreaChart
  title="Data Title"
  kpi={{
    value: '78,909.72',
    badge: {
      icon: '↑',            // any React node
      text: '4.5%',
      label: 'from last week',
    },
  }}
  showKpi={true}
  series={[...]}
  categories={[...]}
/>
```

The badge background uses `var(--chart-kpi-bg, rgba(0,97,33,0.10))` (positive green). For negative trends, override `--chart-kpi-bg` and `--chart-kpi-positive` with red tokens.

## Area Types

### Multi (overlapping, default)

Each series draws its own gradient fill independently. Series are rendered back-to-front so foreground series are never obscured.

## Legend Filtering

Click any legend item to toggle its series. The last visible series cannot be hidden (at-least-one guard). Tooltip shows values for all currently visible series at the hovered category.
