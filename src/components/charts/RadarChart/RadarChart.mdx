## Do / Don't

<div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: 24, marginBottom: 24 }}>

<div style={{ border: '1px solid #bbf7d0', borderRadius: 10, overflow: 'hidden' }}>
  <div style={{ background: '#f0fdf4', padding: '8px 16px', borderBottom: '1px solid #bbf7d0', display: 'flex', alignItems: 'center', gap: 8 }}>
    <span style={{ color: '#16a34a', fontSize: 16, fontWeight: 700 }}>✓</span>
    <span style={{ fontSize: 13, fontWeight: 700, color: '#166534' }}>Do</span>
  </div>
  <div style={{ padding: 16, fontSize: 13, color: '#374151', lineHeight: 1.7 }}>
    <ul style={{ margin: 0, paddingLeft: 18 }}>
      <li>Provide exactly 7 values in each series `data` array to match the 7-axis geometry.</li>
      <li>Use `maxValue` equal to (or slightly above) the highest value in your data for best color distribution.</li>
      <li>Use 2–4 series for readable overlapping polygons. Six series will become visually dense.</li>
      <li>Include meaningful `axisLabels` so users understand each dimension without consulting a legend.</li>
      <li>Enable `showScaleBadges` when the absolute scale matters to your readers.</li>
    </ul>
  </div>
</div>

<div style={{ border: '1px solid #fecaca', borderRadius: 10, overflow: 'hidden' }}>
  <div style={{ background: '#fef2f2', padding: '8px 16px', borderBottom: '1px solid #fecaca', display: 'flex', alignItems: 'center', gap: 8 }}>
    <span style={{ color: '#dc2626', fontSize: 16, fontWeight: 700 }}>✗</span>
    <span style={{ fontSize: 13, fontWeight: 700, color: '#991b1b' }}>Don't</span>
  </div>
  <div style={{ padding: 16, fontSize: 13, color: '#374151', lineHeight: 1.7 }}>
    <ul style={{ margin: 0, paddingLeft: 18 }}>
      <li>Don't use the radar chart for comparing items with more than 7 dimensions — a table or bar chart is clearer.</li>
      <li>Don't pass values above `maxValue` — they will be clamped to the outer ring silently.</li>
