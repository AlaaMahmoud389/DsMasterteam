## States

### Loading

Skeleton fills the ring polygons with animated grey pulses while data is fetching.

<div style={{ background: '#f8fafc', border: '1px solid #e5e7eb', borderRadius: 8, padding: 16, maxWidth: 420, marginBottom: 16 }}>
  <RadarChart title="Card Title" series={[]} loading={true} />
</div>

### Empty

When `series` is empty or `empty={true}`, the grid rings render with a "No data available" message.
