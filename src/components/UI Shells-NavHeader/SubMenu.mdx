## RTL Support

RTL is driven by the `rtl` prop. No `dir="rtl"` wrapper is added to containers. Instead, the column row reverses direction (`flex-direction: row-reverse` on `.content`), and each item renders its text block **before** the icon in the DOM while using `justify-content: flex-end` to push it to the right — matching the exact Figma layout for node 5005:4793 RTL.

## Item States

All interactive states from Figma node [5005:4793](https://www.figma.com/design/WTmRAkJVvw0IvZMA7wBdTC/Masterteam-Ds-For-Experiment-ONLY?node-id=5005-4793). States are handled via CSS pseudo-classes; the label underlines on Hovered / Pressed / Focused.

| State | Light bg overlay | Dark green overlay | Focus border |
|---|---|---|---|
| Default | none | none | — |
| Hovered | `#f3f4f6` | `rgba(22,22,22,0.2)` | — |
| Pressed | `#e5e7eb` | `rgba(22,22,22,0.5)` | — |
| Focused | none | none | `2px solid #1849a9` (light) / `2px solid #fff` (dark) |
