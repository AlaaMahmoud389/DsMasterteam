<div style={{ marginBottom: 40 }}>
  <h2 style={{ fontSize: 22, fontWeight: 600, color: '#111827', marginBottom: 16 }}>Accessibility</h2>
  <ul style={{ color: '#6b7280', lineHeight: 1.8, fontSize: 14, paddingLeft: 20 }}>
    <li>Renders as a native <code>&lt;a&gt;</code> element — fully keyboard navigable via <strong>Tab</strong>.</li>
    <li>Focus ring (<code>:focus-visible</code>) is always visible: <code>#00001C</code> for Primary/Neutral, <code>#FFFFFF</code> for On-color.</li>
    <li>Disabled links use <code>aria-disabled="true"</code> and have <code>href</code> removed to prevent navigation. They remain in the DOM but are not keyboard focusable.</li>
    <li>When <code>target="_blank"</code>, <code>rel="noopener noreferrer"</code> is automatically applied.</li>
    <li>Use <code>aria-label</code> when the link text alone is ambiguous (e.g., multiple "Click here" links on a page).</li>
    <li>The trailing icon is marked <code>aria-hidden="true"</code> and does not affect screen reader output.</li>
    <li>Visited state styling uses CSS <code>:visited</code> — the design explicitly overrides browser defaults to maintain brand colors.</li>
  </ul>
