Four primitives (Line, Rectangle, Circle, Square) each carry a horizontal shimmer gradient animation. Five composite `SkeletonTemplate` variants assemble these primitives into common UI patterns (chart, image card, profile card, inline row, icon list). All tokens sourced from Figma node `4250:1948`.

## Primitives

`SkeletonLine` represents a row of text. Two height variants match the body text scale.

## Shimmer Animation

The shimmer effect is a 90° horizontal gradient that scrolls across the shape:

```
Light ──► Mid ──► Dark ──► Mid ──► Light
rgba(229,231,235, .2) · rgba(210,214,219, .2) · rgba(157,164,174, .2)
```

The gradient background-size is `800 px` wide and animates `background-position` from `-400 px` to `+400 px` over **1.6 s** with `ease-in-out` timing, creating a smooth sweep. This matches the Start → End gradient states in the Figma design tokens.

## Accessibility

- All skeleton primitives and templates render with `aria-hidden="true"` — screen readers skip them entirely.
- Do **not** place interactive content inside a skeleton wrapper.
- Replace skeleton markup with real content as soon as data loads; do not leave skeletons visible indefinitely.
- Users with `prefers-reduced-motion` still see the static gradient shape — the animation pauses gracefully because no `animation` override is needed (the static gradient is always visible as the base).

---

## Usage Guidelines

**Do**
- Use skeletons during the **initial load** of async content, not for refresh/refetch operations (use a spinner for those).
- Match the skeleton shape as closely as possible to the real content it replaces.
- Use `SkeletonTemplate` for common card/list patterns; compose primitives manually only for custom layouts.
- Keep skeleton durations short — if data hasn't loaded in 2–3 s, consider showing an error state instead.

**Don't**
- Don't use skeletons for content that loads in under ~300 ms (a flash of skeleton is worse than no skeleton).
- Don't stack multiple layers of skeleton inside a skeleton (one level of placeholder is sufficient).
- Don't animate indefinitely — always replace with real content once loaded.
- Don't use skeleton for form fields or interactive controls.
