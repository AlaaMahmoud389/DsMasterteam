## Nav Links

The nav-links section (`showNavLinks`) contains five standard link groups (group label + horizontal divider + five footer links) and one special group that houses two button lists:

- **Social Media** — 4 × 32×32 icon buttons (`arrow-right-02-sharp`)
- **Accessibility Tools** — 3 × 32×32 icon buttons (`arrow-right-02-sharp`)

In the Primary variant the icon buttons use a transparent background with a `rgba(255,255,255,0.3)` border.
