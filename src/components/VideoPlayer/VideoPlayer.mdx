{/* ── Usage Guidelines ── */}
<h2 id="usage" style={{ fontSize: 20, fontWeight: 700, color: '#000b36', marginBottom: 8 }}>Usage Guidelines</h2>

<div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: 20, marginBottom: 28 }}>
  <div style={{ border: '1.5px solid #d1fae5', borderRadius: 8, padding: '16px 18px', background: '#f0fdf4' }}>
    <div style={{ fontSize: 13, fontWeight: 700, color: '#065f46', marginBottom: 10 }}>Do</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Always provide a <code>poster</code> image so the dark placeholder is avoided</li>
      <li>Use <code>buttonStyle="primary"</code> when the player sits on a dark page background</li>
      <li>Use <code>buttonStyle="neutral"</code> when the player sits on a white/light card</li>
      <li>Keep <code>buttonSize="large"</code> for hero / above-the-fold placements</li>
      <li>Let users control volume — don't force <code>muted</code> without a clear visual cue</li>
    </ul>
  </div>
  <div style={{ border: '1.5px solid #fee2e2', borderRadius: 8, padding: '16px 18px', background: '#fff5f5' }}>
    <div style={{ fontSize: 13, fontWeight: 700, color: '#991b1b', marginBottom: 10 }}>Don't</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Don't use <code>autoPlay</code> without <code>muted</code> — browsers block unmuted autoplay</li>
      <li>Don't embed the player in a container smaller than ~240 px wide — controls become cramped</li>
      <li>Don't change <code>buttonStyle</code> between plays — pick one style per player instance</li>
      <li>Don't rely on fullscreen for mobile — use the native video player for mobile contexts</li>
    </ul>
  </div>
</div>
