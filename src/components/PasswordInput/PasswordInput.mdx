# Password Input

Password Input is identical to Text Input with one addition: a 20×20px eye icon toggle on the trailing side of the field. Clicking it switches between `type="password"` (browser bullet characters) and `type="text"` (visible plain text). All Text Input props are supported.

## Eye Toggle Behaviour

| Visible state | `type` attribute | Display |
|---|---|---|
| Hidden (default) | `password` | Bullet characters `••••••••` |
| Shown | `text` | Plain text |

- The **EyeOff** icon (slashed eye) is shown when password is hidden — click to reveal
- The **Eye** icon (open eye) is shown when password is visible — click to hide
- In `disabled` state the toggle button is suppressed (`opacity: 0.4`, `pointer-events: none`)
- In `read-only` state the toggle remains active so the user can still inspect the value
