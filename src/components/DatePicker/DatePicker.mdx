## Property: Input Field

`showInputField` adds a labeled date-display field above the calendar. In `mode="single"` one field appears; in `mode="range"` two fields appear (From / To).

<div style={{ display: 'flex', gap: 32, flexWrap: 'wrap', marginBottom: 16 }}>
  <div style={{ background: '#fff', border: '1px solid #e5e7eb', borderRadius: 10, padding: '20px' }}>

    <DatePicker inline showInputField />

  <div style={{ background: '#fff', border: '1px solid #e5e7eb', borderRadius: 10, padding: '20px' }}>

## Property: Dual-Month View

`dualMonth` renders two consecutive calendar months side by side. The main calendar shows `viewMonth`; the second always shows `viewMonth + 1`. Navigation arrows move both calendars simultaneously.

<div style={{ background: '#fff', border: '1px solid #e5e7eb', borderRadius: 10, padding: '20px 24px', marginBottom: 16 }}>
  <div style={{ fontSize: 11, fontWeight: 700, textTransform: 'uppercase', letterSpacing: '.08em', color: '#6b7280', marginBottom: 16 }}>dualMonth + mode="range"</div>
  <DatePicker inline dualMonth mode="range" />
</div>

| Detail | Value |
|---|---|
| Main calendar width | 424px (392px grid + 16px padding each side) |
| Second calendar width | 424px |
| Gap between calendars | Divided by `1px solid #e5e7eb` border |
| Total panel width (dual) | 848px |
| Navigation | Prev arrow on main calendar only · Next arrow on second calendar only |
| Month sync | Second calendar always shows main + 1 month |
| Year dropdown | Independent on each calendar |
| Range across months | Range strip carries across from one calendar into the next |

## Property: Quick Options

`showQuickOptions` adds a 160px sidebar of preset date-range shortcuts. Clicking a shortcut immediately sets the range and navigates the calendar to the start date. Works with both `mode="range"` (recommended) and `mode="single"`.

## Property: Submit Button

`showSubmitButton` adds an **Apply / Cancel** action bar at the bottom of the panel. With this flag enabled, date/range selections become **pending** — `onChange` is only fired when Apply is clicked. Clicking Cancel dismisses without confirming.
