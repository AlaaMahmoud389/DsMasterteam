## Property: Filled

`Filled` tracks whether a colour value has been entered. When `Filled=False` the text area shows the placeholder; when `Filled=True` it shows the hex value in dark text (#000C37) and the swatch shows the current colour.

<div style={{ display: 'flex', gap: 24, flexWrap: 'wrap', marginBottom: 16 }}>
  <div style={{ background: '#fff', border: '1px solid #e5e7eb', borderRadius: 10, padding: '20px' }}>
    <div style={{ fontSize: 11, fontWeight: 700, textTransform: 'uppercase', letterSpacing: '.08em', color: '#6b7280', marginBottom: 10 }}>Filled=False (empty)</div>
    <ColorInput label="Colour" defaultValue="" />
  </div>
  <div style={{ background: '#fff', border: '1px solid #e5e7eb', borderRadius: 10, padding: '20px' }}>
    <div style={{ fontSize: 11, fontWeight: 700, textTransform: 'uppercase', letterSpacing: '.08em', color: '#6b7280', marginBottom: 10 }}>Filled=True (with value)</div>
    <ColorInput label="Colour" defaultValue="#7C53EE" />
  </div>
</div>

| `Filled` | Swatch colour | Text shown | Text colour |
|---|---|---|---|
| `false` | `#E6E8EC` (grey placeholder) | Placeholder text | `#B7BECB` |
| `true` | The entered hex colour | Hex value (e.g. `7C53EE`) | `#000C37` |

## Property: Error

`error` applies a red border and turns the helper text red. In Figma, Error=True only appears on **Read-only** and **Disabled** states — indicating a pre-existing invalid value rather than a live validation error.
