  Follow these guidelines to ensure the Color Input is used appropriately and accessibly.
</p>

<div style={{ display: 'flex', gap: 24, marginBottom: 16, flexWrap: 'wrap' }}>
  <div style={{ flex: '1 1 280px', border: '1px solid #a7f3d0', borderRadius: 8, padding: '16px 20px', background: '#ecfdf5' }}>
    <div style={{ fontSize: 14, fontWeight: 700, color: '#059669', marginBottom: 10 }}>Do</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.7 }}>
      <li>Always provide a label — colour inputs lack inherent context without one.</li>
      <li>Use <code style={{ fontSize: 12, background: 'rgba(0,0,0,0.06)', padding: '1px 4px', borderRadius: 3 }}>showHelperText</code> to indicate expected format (e.g. "6-digit hex like #1849A9").</li>
      <li>Use <code style={{ fontSize: 12, background: 'rgba(0,0,0,0.06)', padding: '1px 4px', borderRadius: 3 }}>required=true</code> for form fields where colour selection is mandatory.</li>
      <li>Use <code style={{ fontSize: 12, background: 'rgba(0,0,0,0.06)', padding: '1px 4px', borderRadius: 3 }}>fieldStyle="filled-darker"</code> inside card panels to maintain visual hierarchy.</li>
      <li>Use with <code style={{ fontSize: 12, background: 'rgba(0,0,0,0.06)', padding: '1px 4px', borderRadius: 3 }}>defaultValue</code> pre-populated for brand-colour settings.</li>
      <li>Wire <code style={{ fontSize: 12, background: 'rgba(0,0,0,0.06)', padding: '1px 4px', borderRadius: 3 }}>onChange</code> to immediately preview the colour in the UI.</li>
    </ul>
