# Rating

**Figma:** [node 4250‑1940](https://www.figma.com/design/WTmRAkJVvw0IvZMA7wBdTC/Masterteam-Ds-For-Experiment-ONLY?node-id=4250-1940)

Two exports:
- **`RatingStar`** — single star, matches the `_RatingStar` Figma component set (24 variants)
- **`Rating`** — interactive 5-star row, matches the `Rating` Figma component set (6 variants)

## Props

### RatingStar

| Prop      | Type                                         | Default    | Description                         |
|-----------|----------------------------------------------|------------|-------------------------------------|
| `size`    | `'large' \| 'medium' \| 'small'`            | `'large'`  | Star size (48 / 32 / 24 px)        |
| `state`   | `'normal' \| 'selected' \| 'half' \| 'pressed'` | `'normal'` | Visual state                    |
| `brand`   | `boolean`                                    | `false`    | Blue (#1849A9) instead of amber     |

### Rating

| Prop       | Type                                | Default   | Description                                  |
|------------|-------------------------------------|-----------|----------------------------------------------|
| `value`    | `number`                            | `0`       | Current rating (0–count, 0.5 increments)     |
| `onChange` | `(n: number) => void`               | —         | Called with new integer value on click        |
| `size`     | `'large' \| 'medium' \| 'small'`   | `'large'` | Star size                                    |
| `brand`    | `boolean`                           | `false`   | Brand (blue) color scheme                    |
| `readOnly` | `boolean`                           | `false`   | Disables interaction, removes pointer events |
| `count`    | `number`                            | `5`       | Number of stars                              |

## Usage

```jsx
import { Rating, RatingStar } from './Rating';

// Interactive 5-star rating
const [rating, setRating] = useState(0);
<Rating value={rating} onChange={setRating} size="large" />

// Read-only display (e.g., from API)
<Rating value={4.5} readOnly size="medium" />

// Brand color
<Rating value={3} brand size="large" />

// Individual star for custom layouts
<RatingStar size="large" state="selected" />
<RatingStar size="medium" state="half" brand />
<RatingStar size="small" state="pressed" />
```
