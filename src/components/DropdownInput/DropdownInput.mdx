# DropdownInput

A select-style field sharing TextInput's visual design. Clicking the field opens a dropdown list; the chevron rotates 180° when open. Supports four list-item layouts, group labels, single and multi selection, all six field states, three field variants, two sizes, and RTL.

---

## Interactive Demo

  const [val, setVal] = useState(null);
  const items = [
    { type: 'group', label: 'Fruits' },

    { type: 'item', value: 'banana',  label: 'Banana' },

        placeholder="Select a category"

        listType="text"

        onSelectionChange={setVal}

## Dropdown List Items

The dropdown list opens below the field when clicked. It supports four distinct item layouts controlled by the `listType` prop. All types share the same container and state styling.

---

### 1 — Text Only · Single Select (`listType="text"`)

Each item shows a text label. When an item is selected a blue tick (`#1849A9`) appears on the trailing edge; an invisible spacer preserves alignment for unselected rows. Supports group labels.

export const DemoTextSingle = () => {
  const [val, setVal] = useState('banana');
  const items = [
    { type: 'group', label: 'Fruits' },
    { type: 'item', value: 'apple',   label: 'Apple' },
    { type: 'item', value: 'banana',  label: 'Banana' },
    { type: 'item', value: 'cherry',  label: 'Cherry', disabled: true },
    { type: 'group', label: 'Vegetables' },
    { type: 'item', value: 'carrot',  label: 'Carrot' },
    { type: 'item', value: 'spinach', label: 'Spinach' },
  ];
  return (
    <div style={{ width: 280, paddingBottom: 240 }}>
      <DropdownInput label="Select a fruit" items={items} listType="text"
        selectedValue={val} onSelectionChange={setVal}
        placeholder="Choose one" defaultOpen={true} />
    </div>
  );
};

<DemoTextSingle />

**Anatomy of a text-only single-select list:**
- Group label row: semibold 14px, padding 8px top / left / right, no bottom padding, no hover state
- Item row: regular 14px, 8px padding all sides, `#000B36` text
- Selected item: same as above + blue tick icon (16×16) on trailing edge
- Disabled item: background `#D2D6DB`, text `#6C7C96`, not interactive

### 2 — Text Only · Multi Select (`listType="text-multi"`)

Each item shows a small checkbox (20×20, `size="sm"`) on the leading edge and text on the trailing side with an 8px gap. The dropdown stays open after each selection. The field shows `"N selected"` when two or more items are chosen.
