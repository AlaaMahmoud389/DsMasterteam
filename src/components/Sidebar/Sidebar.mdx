# Sidebar

A full navigation sidebar with logo, search, menu items, a dismissible featured card, and a user profile section at the bottom. Supports three variants: **LTR**, **RTL**, and **Icon-only** (collapsed).

## Variant — RTL

<Canvas of={Stories.RTL} />

In RTL mode `dir="rtl"` is applied to the sidebar container. CSS logical properties (`border-inline-end`, `padding-inline-start`, `inset-inline-end`) automatically mirror the layout so the border appears on the left and all content flows right-to-left.

---

## Variant — Icon Only

<Canvas of={Stories.IconOnly} />

In icon-only mode:
- Width shrinks to **80px** (padding reduces to 12px horizontal)
- Logo text is hidden; only the mark is shown
- Search bar is hidden
- Menu items show only their **24px icons**, centred
- Featured card is hidden
- Profile shows only the **avatar**
