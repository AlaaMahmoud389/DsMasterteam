## With Icon

The `withIcon` prop prepends a home icon as a root anchor before all items. Most useful in deep hierarchies or overflow situations.

## Overflow

When `items.length > maxVisible` (default 5), the middle items collapse to a `…` button. Clicking it opens a dropdown listing the hidden items plus a "Show all" option that expands everything inline.

## RTL Support

Pass `dir="rtl"` to flip separators to `‹` (chevron-left) and reverse item order for right-to-left reading.
