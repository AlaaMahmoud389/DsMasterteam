{/* ── Usage Guidelines ── */}
<h2 id="usage" style={{ fontSize: 20, fontWeight: 700, color: '#000b36', marginBottom: 8 }}>Usage Guidelines</h2>

<div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: 20, marginBottom: 28 }}>
  <div style={{ border: '1.5px solid #d1fae5', borderRadius: 8, padding: '16px 18px', background: '#f0fdf4' }}>
    <div style={{ fontSize: 13, fontWeight: 700, color: '#065f46', marginBottom: 10 }}>Do</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Use for image galleries, featured articles, or onboarding step sequences</li>
      <li>Keep slide count between 2–7 — more slides create poor user orientation</li>
      <li>Use <code>loop=true</code> for continuous browsing contexts such as galleries</li>
      <li>Use <code>navVariant="primary"</code> on hero and banner areas</li>
      <li>Use <code>navVariant="subtle"</code> inside cards or content panels</li>
      <li>Always include <code>showDots</code> when users may enter from any slide</li>
      <li>Test with keyboard — verify all dots and nav buttons reach Tab focus</li>
    </ul>
  </div>
  <div style={{ border: '1.5px solid #fee2e2', borderRadius: 8, padding: '16px 18px', background: '#fff5f5' }}>
    <div style={{ fontSize: 13, fontWeight: 700, color: '#991b1b', marginBottom: 10 }}>Don't</div>
    <ul style={{ margin: 0, paddingLeft: 18, fontSize: 13, color: '#374151', lineHeight: 1.8 }}>
      <li>Don't hide mandatory form fields or required steps inside slides</li>
      <li>Don't use carousel as primary navigation — use tabs or a sidebar instead</li>
      <li>Don't <code>autoPlay</code> news, alerts, or time-sensitive critical content</li>
      <li>Don't use more than 7 slides without switching to a different pattern</li>
      <li>Don't mix <code>navVariant</code> or <code>navSize</code> within the same carousel</li>
      <li>Don't disable both <code>showNavigation</code> and <code>showDots</code> simultaneously</li>
    </ul>
  </div>
</div>
