## State Table

| State | Trigger | Primary bg | Subtle bg | Icon |
|---|---|---|---|---|
| Default | Resting | `#1849a9` | `#f3f4f6` | white / `#000b36` |
| Hover | `:hover` | `#194185` | `#e5e7eb` | unchanged |
| Pressed | `:active` | `#102a56` | `#d2d6db` | unchanged |
| Focused | `:focus-visible` | `#1849a9` + ring | `#f3f4f6` + ring | unchanged |
| Disabled | `disabled` prop | `#d2d6db` | `#d2d6db` | `#6c7c96` |

**Focus ring pattern** — Primary: `box-shadow: 0 0 0 2px #1849a9, 0 0 0 5px #ffffff` (inner blue + outer white). Subtle: `box-shadow: 0 0 0 2px #f3f4f6, 0 0 0 5px #00001c` (inner gray + outer near-black from `Carousel/Focus Ring/focus ring`).

**Disabled** — uses dedicated tokens (`--carousel-disabled-bg: #d2d6db` / `--carousel-disabled-icon: #6c7c96`), not opacity.

## Code Examples

```jsx
import { Carousel, CarouselNavButton } from '@/components/Carousel';

// Default — primary nav, md size, 4 slides
<Carousel
  slides={[
    <MyCard title="Slide 1" />,
    <MyCard title="Slide 2" />,
    <MyCard title="Slide 3" />,
    <MyCard title="Slide 4" />,
  ]}
/>

// Subtle variant, large buttons
<Carousel
  navVariant="subtle"
  navSize="lg"
  slides={[ <MyCard title="A" />, <MyCard title="B" /> ]}
/>

// Dots only (no nav arrows)
<Carousel
  showNavigation={false}
  showDots={true}
  slides={slides}
/>

// Loop + auto-play every 4 seconds
<Carousel
  loop={true}
  autoPlay={true}
  interval={4000}
  slides={slides}
/>

// RTL Arabic
<Carousel
  dir="rtl"
  slides={[
    <div style={{ direction: 'rtl' }}>الشريحة الأولى</div>,
    <div style={{ direction: 'rtl' }}>الشريحة الثانية</div>,
  ]}
/>

// Standalone nav button (custom prev/next wiring)
<CarouselNavButton
  direction="prev"
  variant="primary"
  size="md"
  aria-label="Previous item"
  onClick={handlePrev}
/>
<CarouselNavButton
  direction="next"
  variant="subtle"
  size="md"
  disabled={isLastSlide}
  onClick={handleNext}
/>
```
