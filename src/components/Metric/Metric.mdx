## RTL Support

<div id="rtl-support" style={{ border: '1px solid #e5e7eb', borderRadius: 10, overflow: 'hidden', marginBottom: 24 }}>
  <Canvas of={MetricStories.RTLAllTypes} />
</div>

Pass `rtl={true}` to enable the RTL layout. The component uses **structural conditional rendering** (not a CSS `dir` attribute on the container) to mirror each section:

- **Small Chart RTL**: kebab moves to the left; label + icon moves to the right; sparkline moves to the left, value block to the right; View Report moves to the left with ← arrow, settings button to the right.
- **Large Chart RTL**: label row appears _before_ the chart; change subtext appears to the left of the change badge; View Report and settings swap sides.
