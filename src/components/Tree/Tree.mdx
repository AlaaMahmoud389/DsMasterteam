# Tree

A hierarchical list component for displaying nested data structures. Supports up to 4 levels of nesting, 5 interaction states, optional icons, action icons, switches, and full RTL layout.

## Row Anatomy

Each row follows this left-to-right layout:

```
[chevron 24px]  gap 12px  [icon 24px]  gap 12px  [label flex:1]  gap 12px  [icon1] [icon2] [icon3] [switch]
```

- **Chevron** — always present; spacer (24×24px invisible block) when the item has no children
- **Icon** — optional lead icon (24×24px)
- **Label** — flex:1, truncates with ellipsis if too long
- **Right group** — any combination of up to 3 action icons and/or a switch

## With Switch

<Canvas of={Stories.WithSwitch} />

The switch inherits the disabled state from the tree item. When `state="disabled"`, the switch renders with `state="disabled"` and its `onChange` is suppressed.

---

## Interactive Tree

<Canvas of={Stories.Interactive} />

Clicking a row with `children` toggles its expanded state. The chevron rotates 90° when expanded, 0° when collapsed (180° in RTL collapsed).

## RTL

<Canvas of={Stories.RTL} />

Set `rtl={true}` on `<Tree>` to flip the layout. Indentation uses `paddingInlineStart` so levels automatically mirror. The chevron points left (180°) when collapsed in RTL, and 90° (down) when expanded.
