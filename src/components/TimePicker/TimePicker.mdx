## Overview

<div style={{ display: 'flex', flexDirection: 'column', gap: 24, marginBottom: 16 }}>
  <TimePicker type="Stepper"  />
  <TimePicker type="Dropdown" />
  <TimePicker type="Input"    />
  <TimePicker type="Timer"    />
</div>

Four interaction patterns · 12-hour format with AM / PM · optional seconds · full RTL support. All tokens sourced from Figma node `4770:12915`.

---

## Types

### Stepper

Increment / decrement each time unit with up and down arrow buttons. Ideal for precise value entry in compact interfaces.

<div style={{ marginBottom: 24 }}>
  <TimePicker type="Stepper" />
</div>

### Dropdown

Native `<select>` elements with labels above. Best for touch-friendly interfaces or where keyboard navigation through a list is preferred.

<div style={{ marginBottom: 24 }}>
  <TimePicker type="Dropdown" />
</div>

### Input

Displays the full time as a formatted string. The `typing` prop adds a blinking cursor for active input states.

<div style={{ display: 'flex', flexDirection: 'column', gap: 12, marginBottom: 24 }}>
  <TimePicker type="Input" />
  <TimePicker type="Input" typing={true} hours="09" minutes="30" />
</div>

### Timer

Large, prominent number display — suited for countdown timers, stopwatches, or any context that requires time to be immediately readable from a distance.

<div style={{ marginBottom: 24 }}>
  <TimePicker type="Timer" />
</div>

## AM / PM

The period toggle appears in all four types. The active period is highlighted with the brand blue background (`#eff8ff`) and brand text (`#1849a9`).

<div style={{ display: 'flex', gap: 16, flexWrap: 'wrap', marginBottom: 24 }}>
  <TimePicker type="Stepper" period="AM" />
  <TimePicker type="Stepper" period="PM" />

## Without Seconds

Set `showSeconds={false}` to hide the seconds unit across all four types.

<div style={{ display: 'flex', flexDirection: 'column', gap: 16, marginBottom: 24 }}>
  <TimePicker type="Stepper"  showSeconds={false} />
  <TimePicker type="Dropdown" showSeconds={false} />
  <TimePicker type="Input"    showSeconds={false} />
  <TimePicker type="Timer"    showSeconds={false} />
</div>

## RTL Support

Set `rtl={true}` to mirror the layout for Arabic or Hebrew content. The `dir="rtl"` attribute is applied automatically to the root element.

<div style={{ display: 'flex', flexDirection: 'column', gap: 16, marginBottom: 24 }}>
  <TimePicker type="Stepper"  rtl={true} />
  <TimePicker type="Dropdown" rtl={true} />
  <TimePicker type="Input"    rtl={true} />
  <TimePicker type="Timer"    rtl={true} />
</div>

### Timer Usage

The Timer type is intended for display purposes only — countdown timers, elapsed time, or stopwatch readouts. It should not be used as an input control.
