<div style={{ marginBottom: 48 }}>
  <h2 style={{ fontSize: 22, fontWeight: 600, color: '#111827', marginBottom: 16 }}>Accessibility</h2>
  <ul style={{ fontSize: 14, color: '#374151', lineHeight: 1.8, paddingLeft: 20 }}>
    <li>The spinner element has <code>role="status"</code> and <code>aria-live="polite"</code>, so screen readers announce it without interrupting the user.</li>
    <li>The <code>label</code> prop sets <code>aria-label</code> on the element — use a descriptive string like <code>"Saving changes…"</code> when possible.</li>
    <li>Respects <code>prefers-reduced-motion</code> — consider pausing the animation for users who prefer reduced motion by adding a media query in your global CSS.</li>
  </ul>

  <pre style={{ background: '#f9fafb', border: '1px solid #e5e7eb', borderRadius: 6, padding: 20, fontSize: 13, lineHeight: 1.7, overflow: 'auto', marginTop: 16 }}>{`/* Add to your global CSS for reduced-motion support */
