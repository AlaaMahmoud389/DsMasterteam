## Token Usage Rules

<div style={{ display: 'flex', flexDirection: 'column', gap: 12, marginBottom: 16 }}>
<div style={{ border: '1px solid #a7f3d0', borderRadius: 10, padding: '12px 16px', background: '#f0fdf4', fontSize: 13, color: '#065f46' }}>
<span style={{ fontWeight: 700 }}>Do:</span> Always use CSS custom properties — <code style={{ background: 'rgba(0,0,0,0.07)', padding: '1px 5px', borderRadius: 3 }}>var(--color-primary-bg)</code> not <code style={{ background: 'rgba(0,0,0,0.07)', padding: '1px 5px', borderRadius: 3 }}>#1849a9</code>. This allows theme overrides and guarantees token consistency across all components.
</div>
<div style={{ border: '1px solid #fecaca', borderRadius: 10, padding: '12px 16px', background: '#fef2f2', fontSize: 13, color: '#991b1b' }}>
<span style={{ fontWeight: 700 }}>Don't:</span> Add new color tokens without a corresponding Figma token. Every token in <code style={{ background: 'rgba(0,0,0,0.07)', padding: '1px 5px', borderRadius: 3 }}>tokens.css</code> must map to a named Figma variable with a documented Figma token path in the comment.
</div>
