## Usage rules

<div style={{ display: 'flex', flexDirection: 'column', gap: 10, marginBottom: 16 }}>
<div style={{ border: '1px solid #a7f3d0', borderRadius: 10, padding: '12px 16px', background: '#f0fdf4', fontSize: 13, color: '#065f46' }}>
<div style={{ fontWeight: 700, marginBottom: 6 }}>Do</div>
<div style={{ display: 'flex', flexDirection: 'column', gap: 4 }}>
<div>✓ Use Figma effect tokens — apply shadow levels (xs → 3xl) to match design elevation intent.</div>
<div>✓ Use <code style={{ background: 'rgba(0,0,0,0.06)', padding: '1px 4px', borderRadius: 3, fontSize: 11 }}>shadow-xs</code> or <code style={{ background: 'rgba(0,0,0,0.06)', padding: '1px 4px', borderRadius: 3, fontSize: 11 }}>shadow-sm</code> for inputs, chips, and table rows.</div>
<div>✓ Use <code style={{ background: 'rgba(0,0,0,0.06)', padding: '1px 4px', borderRadius: 3, fontSize: 11 }}>shadow-lg</code> – <code style={{ background: 'rgba(0,0,0,0.06)', padding: '1px 4px', borderRadius: 3, fontSize: 11 }}>shadow-xl</code> for dropdowns, tooltips, and popovers.</div>
<div>✓ Use <code style={{ background: 'rgba(0,0,0,0.06)', padding: '1px 4px', borderRadius: 3, fontSize: 11 }}>shadow-2xl</code> / <code style={{ background: 'rgba(0,0,0,0.06)', padding: '1px 4px', borderRadius: 3, fontSize: 11 }}>shadow-3xl</code> for modals and full-screen drawers.</div>
</div>
</div>
<div style={{ border: '1px solid #fecaca', borderRadius: 10, padding: '12px 16px', background: '#fef2f2', fontSize: 13, color: '#991b1b' }}>
<div style={{ fontWeight: 700, marginBottom: 6 }}>Don't</div>
<div style={{ display: 'flex', flexDirection: 'column', gap: 4 }}>
<div>✕ Do not write custom <code style={{ background: 'rgba(0,0,0,0.06)', padding: '1px 4px', borderRadius: 3, fontSize: 11 }}>box-shadow</code> values — always use the token CSS values above.</div>
<div>✕ Do not use <code style={{ background: 'rgba(0,0,0,0.06)', padding: '1px 4px', borderRadius: 3, fontSize: 11 }}>box-shadow: none</code> to remove elevation without design approval.</div>
<div>✕ Do not add <code style={{ background: 'rgba(0,0,0,0.06)', padding: '1px 4px', borderRadius: 3, fontSize: 11 }}>filter: drop-shadow()</code> — use <code style={{ background: 'rgba(0,0,0,0.06)', padding: '1px 4px', borderRadius: 3, fontSize: 11 }}>box-shadow</code> only.</div>
