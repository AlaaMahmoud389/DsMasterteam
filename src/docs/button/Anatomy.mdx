# Anatomy

| Part | Description |
|---|---|
| Container | Bounding box carrying background, border, and radius tokens |
| Label | Text string describing the action |
| Leading Icon | Optional icon placed before the label (flips in RTL) |
| Trailing Icon | Optional icon placed after the label (flips in RTL) |
| Loading Spinner | Replaces or overlays the label during async operations |
| Focus Ring | Visible outline on keyboard focus |
