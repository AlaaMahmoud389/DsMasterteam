# States

| State | Description |
|---|---|
| `Default` | Resting state |
| `Hovered` | Pointer over button — background darkens one step |
| `Pressed` | Active tap/click — deeper background or scale feedback |
| `Selected` | Toggle button is active |
| `Focused` | Keyboard focus ring visible |
| `Loading` | Spinner shown; button is non-interactive |
| `Disabled` | Non-interactive; 40 % opacity |
