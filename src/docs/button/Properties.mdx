# Properties

| Property | Type | Default | Description |
|---|---|---|---|
| `variant` | `primary` \| `secondary-solid` \| `neutral` \| `transparent` \| `destructive` | `primary` | Visual style |
| `size` | `large` \| `medium` \| `small` | `medium` | Button height |
| `label` | `string` | — | Button text |
| `leadingIcon` | `ReactNode` | `null` | Icon before label |
| `trailingIcon` | `ReactNode` | `null` | Icon after label |
| `isLoading` | `boolean` | `false` | Shows spinner, disables interaction |
| `isDisabled` | `boolean` | `false` | Disables the button |
| `isSelected` | `boolean` | `false` | Toggle active state |
| `type` | `button` \| `submit` \| `reset` | `button` | Native button type |
| `onClick` | `function` | — | Click handler |
