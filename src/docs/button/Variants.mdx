# Variants

| Style | Usage |
|---|---|
| `Primary` | Single most important action on the screen |
| `Secondary-Solid` | Secondary action needing strong visual weight |
| `Neutral` | Low-emphasis action; default for most secondary actions |
| `Transparent` | Ghost/text-level action with no background |
| `Destructive` | Irreversible or dangerous actions (delete, revoke) |

### Sub-variants

- **Button-menu** — trailing chevron; opens a dropdown or menu
- **Button-Close** — icon-only × button; closes modals, toasts, or panels
