# Icon Usage

- Icons are **optional** in all variants except Button-Close (icon-only).
- **Leading icon**: reinforces the label meaning (e.g., `+` Add, `↓` Download).
- **Trailing icon**: directional hints or dropdowns (e.g., chevron for Button-menu).
- Icon size: **20 px** for Large/Medium, **16 px** for Small.
- Never use two icons simultaneously without a label.
- Icon-only buttons **must** have an `aria-label`.
