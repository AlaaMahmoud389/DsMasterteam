# Sizes

| Size | Height | Font size | Padding (H) | Use case |
|---|---|---|---|---|
| `Large` | 48 px | 16 px | 20 px | Hero CTAs, standalone forms |
| `Medium` | 40 px | 14 px | 16 px | Default; most UI contexts |
| `Small` | 32 px | 14 px | 12 px | Dense tables, toolbars, inline actions |
